# Grok usage

BB's Usage limits page only covers Codex, Claude Code, and Cursor. This plugin adds Grok Build.

Run `bb grok-usage show` or `bb grok-usage show --json`. Needs `grok login` on the machine.

Grok Build is a SuperGrok-and-up feature. Plan labels: SuperGrok Lite, SuperGrok, SuperGrok Plus, SuperGrok Heavy.
